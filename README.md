## Contenu du dépôt

```
index.html      page unique du portfolio, contenu et fiches projets
404.html        page affichée si une adresse n'existe pas
style.css       feuille de styles, variables de couleurs en tête de fichier
script.js       filtres, ouverture des fiches projets, protection de l'adresse e-mail
favicon.svg     icône du site
cv.pdf          curriculum vitae
images/         captures et illustrations des projets
```

## Choix techniques

Site statique, sans framework ni dépendance externe, hébergé par GitHub Pages.

- Mise en page en CSS grid et flexbox, variables CSS pour la palette
- Fiches projets en `<dialog>` natif, sans bibliothèque
- Filtrage des projets par domaine en JavaScript, sans rechargement de page
- Mise en page adaptative jusqu'à 400 px de large
- Textes alternatifs sur les images de contenu, focus clavier visible,
  animations désactivées si le système le demande

## Consulter le site en local

Aucune installation n'est nécessaire : ouvrir `index.html` dans un navigateur suffit.
